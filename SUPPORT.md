# Support

For usage questions, bug reports and feature requests, open a [GitHub issue](https://github.com/paulchum/agent-effect-gate/issues). Include the release version, Python version, Linux distribution, relevant configuration with secrets removed, expected behavior and observed behavior.

Use [GitHub private vulnerability reporting](https://github.com/paulchum/agent-effect-gate/security/advisories/new) for security issues. Do not post tokens, private keys, task payloads, state databases or customer data publicly.

Community support is best effort. No response time or service-level agreement is offered with the MIT core. Planned commercial options are described in [COMMERCIAL.md](COMMERCIAL.md); they are not available in this release.
